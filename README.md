# Production Zombe / 26e portfolio

Готовый статический лендинг в выбранном дизайне.

## Запуск
Открой `index.html` напрямую или запусти любой static server, например:

```bash
python -m http.server 8080
```

Затем открой `http://localhost:8080`.

## Что заменить перед публикацией
- ссылки Telegram / Instagram / Vimeo;
- `hello@example.com`;
- showreel-заглушку на реальное видео;
- фотографии при необходимости на оригиналы без Telegram UI.

Для Vercel можно загрузить папку как Static Site без build command.
